# Внесение изменений в CPVP.PRO

Спасибо за интерес к проекту. Репозиторий пока находится на раннем этапе, поэтому любые изменения должны быть небольшими, понятными и легко проверяемыми.

## Основные правила

1. Создавайте отдельную ветку для каждой задачи.
2. Не добавляйте зависимости без измеримой пользы.
3. Не усложняйте текущую landing page без необходимости.
4. Проверяйте мобильную версию после каждого изменения интерфейса.
5. Сохраняйте единый визуальный стиль проекта.
6. Не коммитьте секреты, токены, `.env`-файлы и локальные настройки редактора.

## Локальная проверка

Откройте проект через локальный HTTP-сервер:

```bash
python -m http.server 8080
```

Затем проверьте страницу по адресу `http://localhost:8080`.

Перед отправкой изменений убедитесь, что:

- страница открывается без ошибок;
- в DevTools нет лишних сетевых запросов;
- внешний CSS и JavaScript не добавлены без необходимости;
- layout корректно работает на desktop и mobile;
- анимации отключаются при `prefers-reduced-motion`;
- все новые файлы имеют понятные имена и назначение.

## Pull Request

В описании Pull Request укажите:

- что изменено;
- зачем это нужно;
- как проверялась работа;
- есть ли визуальные изменения;
- влияет ли изменение на производительность.

Для визуальных изменений желательно приложить скриншоты до и после.
