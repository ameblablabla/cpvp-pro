# CPVP.PRO production branding pack

Generated from the fixed CPVP.PRO visual tokens for web integration.

Files:

- `logo.svg` — horizontal wordmark.
- `logo-mark.svg` — compact logo mark.
- `logo-mark.png` — 512×512 raster mark.
- `favicon.svg` — vector favicon.
- `favicon.ico` — multi-size browser favicon.
- `apple-touch-icon.png` — 180×180 touch icon.
- `og-image.png` — 1200×630 Open Graph image.
- `social-cover.png` — 1640×624 social cover.
- `announcement-template.png` — 1080×1350 announcement post.
- `story-template.png` — 1080×1920 story format.
- `site.webmanifest` — basic web manifest.

The Canva designs remain editable concept sources. This pack contains optimized production-oriented files for the repository.
