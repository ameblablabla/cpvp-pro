# CPVP.PRO community plan

## Назначение

CPVP.PRO должен развиваться как комьюнити-платформа, а не только как сайт с рейтингами. Этот документ фиксирует базовую структуру внешних каналов и внутренних процессов.

## Внешние каналы

Минимальный набор каналов:

- Discord — основной канал сообщества;
- Telegram — короткие обновления и анонсы;
- GitHub — технический прогресс и документация;
- cpvp.pro — основная публичная точка входа.

## Discord structure

```text
INFORMATION
├── announcements
├── rules
├── roadmap
└── faq

COMMUNITY
├── general
├── crystal-pvp
├── find-duel
├── training
└── feedback

SUPPORT
├── help
├── reports
└── appeals

TEAM
├── moderators
├── reviewers
└── development
```

## Роли сообщества

- Member;
- Verified player;
- Tester;
- Reviewer;
- Moderator;
- Administrator.

## Формат анонсов

Каждый анонс должен содержать:

1. Короткий заголовок.
2. Одно основное изменение.
3. Ссылку на подробности.
4. Дату публикации.
5. Статус: preview, update, release или maintenance.

## Набор тестеров

Для первого закрытого теста достаточно небольшой группы пользователей, которые смогут проверить:

- мобильную версию;
- navigation;
- TierList;
- обучение;
- форум;
- понятность правил;
- скорость загрузки.

## Модерация сообщества

- Решения модераторов должны фиксироваться.
- Жалобы должны обрабатываться по понятной очереди.
- Апелляции должны рассматриваться отдельно от исходного решения.
- Важные обновления правил должны публиковаться в announcements.
