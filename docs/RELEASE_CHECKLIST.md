# CPVP.PRO release checklist

## Перед публикацией изменений

- [ ] Проверить главную страницу на desktop.
- [ ] Проверить главную страницу на mobile.
- [ ] Проверить страницу `404.html`.
- [ ] Проверить, что домен `cpvp.pro` открывается корректно.
- [ ] Проверить, что `CNAME` содержит только `cpvp.pro`.
- [ ] Проверить отсутствие неожиданных внешних запросов.
- [ ] Проверить отсутствие ошибок в консоли браузера.
- [ ] Проверить, что анимации не мешают чтению.
- [ ] Проверить режим `prefers-reduced-motion`.
- [ ] Проверить ссылки в README.
- [ ] Проверить успешное выполнение GitHub Actions.

## Перед первым полноценным релизом платформы

- [ ] Утвердить структуру страниц.
- [ ] Утвердить UI-kit.
- [ ] Утвердить правила платформы.
- [ ] Утвердить правила форума.
- [ ] Утвердить критерии TierList.
- [ ] Подготовить FAQ.
- [ ] Проверить роли пользователей.
- [ ] Проверить мобильные сценарии.
- [ ] Проверить доступность интерфейса.
- [ ] Проверить резервный план на случай ошибки деплоя.
