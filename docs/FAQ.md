# CPVP.PRO FAQ

## Что такое CPVP.PRO?

CPVP.PRO — будущая платформа для Crystal PvP-сообщества. На ней планируются обучение, TierList игроков, профили, форум и комьюнити-инструменты.

## Когда состоится запуск?

Точная дата ещё не объявлена. Сейчас готовятся дизайн-система, структура продукта и временная landing page.

## Что уже доступно?

Пока доступна временная страница проекта на домене `cpvp.pro`. Полноценные разделы появятся позже.

## Какие разделы планируются?

- обучение;
- TierList;
- профили игроков;
- форум;
- правила;
- FAQ;
- настройки аккаунта;
- инструменты модерации.

## Как попасть в TierList?

Для этого будет предусмотрена отдельная процедура review. Перед запуском будут опубликованы финальные критерии и правила подачи материалов.

## Можно ли оспорить решение по TierList?

Да. Для спорных случаев планируется повторный review с указанием причины и дополнительных материалов.

## Будет ли мобильная версия?

Да. Интерфейс проектируется для desktop и mobile.

## Будет ли Discord или Telegram?

Комьюнити-каналы рассматриваются. Финальный список будет опубликован ближе к запуску.

## Можно ли стать модератором?

Позже будет подготовлен отдельный порядок набора и отбора модераторов.

## Где следить за прогрессом?

Текущий roadmap хранится в `docs/ROADMAP.md` в репозитории проекта.
