# CPVP.PRO forum rules

## Назначение

Форум нужен для обсуждений Crystal PvP, обучения, дуэлей и развития комьюнити. Эти правила задают базовые нормы общения.

## Общение

1. Пишите по теме раздела и конкретной темы.
2. Не публикуйте оскорбления, травлю и провокации.
3. Не создавайте одинаковые темы повторно.
4. Не поднимайте старые темы без новой полезной информации.
5. Не публикуйте бессодержательные сообщения ради активности.

## Реклама

- Реклама серверов, услуг и сообществ допускается только в специально разрешённых разделах.
- Скрытая реклама и массовая рассылка запрещены.
- Ссылки должны быть понятными и относиться к теме обсуждения.

## Контент

- Не публикуйте чужие персональные данные.
- Не выдавайте чужие материалы за свои.
- Не размещайте вредоносные файлы и подозрительные ссылки.
- Не публикуйте материалы, которые мешают нормальной работе форума.

## Темы о TierList

- Обсуждение рейтингов должно оставаться аргументированным.
- Решения reviewers нельзя заменять массовыми спорами в комментариях.
- Для официального пересмотра используется отдельная процедура review.

## Действия модераторов

При нарушении правил модератор может:

1. Отредактировать заголовок темы.
2. Переместить тему в подходящий раздел.
3. Скрыть отдельное сообщение.
4. Закрыть тему.
5. Выдать предупреждение.
6. Ограничить доступ к форуму.

## Апелляции

Если пользователь считает действие модератора ошибочным, он может запросить пересмотр решения и кратко объяснить причину.
