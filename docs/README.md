# CPVP.PRO documentation

Документация приведена к единой структуре. Устаревшие черновики и повторяющиеся snapshots удаляются после переноса подтверждённых требований.

The documentation is organized into a single structure. Outdated drafts and duplicate snapshots are removed after confirmed requirements are migrated.
