# CPVP.PRO project overview

## Product position

CPVP.PRO is a bilingual Russian-English Crystal PvP community platform.

TierList and tier testing are important product features, but they are not the whole product. The platform is intended to combine:

- learning materials;
- player profiles;
- Vanilla CPVP TierList;
- tier-test applications;
- rules and FAQ;
- notifications;
- moderation tools;
- Find Duel;
- teams;
- external community channels.

## First delivery priority

The first public product release should prioritize learning. TierList and tier-test applications are core later features, but the platform should not begin with them before the learning section is ready.

## Language support

- browser-language auto-detection;
- manual language switcher in navbar;
- all public rules, FAQ and learning materials in Russian and English;
- bilingual Discord server.

## Supported game

- Minecraft Java Edition only;
- gameplay on PC or laptop;
- mobile site for convenient viewing, applications, profiles, learning, rules and notifications.

## First competitive category

```text
Vanilla CPVP
```

Vanilla CPVP is one overall category. Detailed kit rules will be finalized during implementation.

## Development entry point

Before feature work:

1. Review [`ROADMAP.md`](ROADMAP.md).
2. Review [`DEVELOPMENT_START_CHECKLIST.md`](DEVELOPMENT_START_CHECKLIST.md).
3. Review the player-facing rules under `docs/rules/`.
4. Choose the stack.
5. Start with learning, accounts, profiles and safe Minecraft account linking.
