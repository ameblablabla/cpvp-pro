# CPVP.PRO player profiles

## Public identity

- public profile name equals the current Minecraft username;
- profile name updates automatically after a Minecraft username change;
- previous Minecraft usernames are public;
- Minecraft UUID remains an internal stable identifier;
- Minecraft skin is public.

## Public profile fields

- Minecraft username;
- Minecraft skin;
- Vanilla CPVP tier;
- tier-change history;
- Unranked, Retired, Inactive and Restricted states;
- tester status;
- senior tester status;
- region;
- Discord contact for authenticated users only;
- forum activity when forum launches;
- completed guides;
- registration date;
- win/loss statistics;
- achievements and badges.

## Match highlights

Only large or important official matches should appear publicly as profile highlights.

## Following

Players can follow other players and configure notifications for public activity such as tier changes, important matches and team activity.

## Privacy

Profiles include private settings. Exact visibility controls will be finalized during implementation.

## Cosmetics

Rank-based profile cosmetics start at `HT3+` and become stronger at higher tiers.

Suggested progression:

```text
HT3+: accent color, profile frame, banner
LT2+: animated border, featured match, badge layout
HT2+: advanced effects, featured guide, more highlight slots
LT1+: premium theme, rare frame set, expanded highlights
HT1: exclusive champion-style visual package
```

Paid learning subscription tiers may also unlock top-level profile cosmetics comparable to HT1. Subscription cosmetics and rank cosmetics must remain visually distinguishable.
