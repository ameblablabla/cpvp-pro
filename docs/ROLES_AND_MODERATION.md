# CPVP.PRO roles and moderation

## Назначение

Этот документ фиксирует минимальную модель ролей для будущей платформы. Реализация может меняться, но интерфейс и backend должны опираться на единые понятия.

## Роли

### Guest

Неавторизованный посетитель.

Доступ:

- просмотр публичных страниц;
- чтение гайдов;
- просмотр TierList;
- чтение форума;
- просмотр публичных профилей.

### Member

Обычный зарегистрированный пользователь.

Дополнительно доступно:

- настройка профиля;
- сохранение прогресса обучения;
- создание тем и ответов на форуме;
- отправка жалоб;
- получение уведомлений.

### Verified player

Игрок с подтверждённым профилем.

Дополнительно доступно:

- отображение значка подтверждения;
- расширенная карточка профиля;
- участие в рейтинговых разделах;
- история изменений TierList.

### Moderator

Пользователь, который поддерживает порядок на платформе.

Доступ:

- обработка жалоб;
- скрытие нарушающего контента;
- предупреждения пользователям;
- модерация тем и ответов;
- просмотр очереди проверки рейтингов.

### Tier reviewer

Отдельная роль для проверки рейтингов игроков.

Доступ:

- просмотр заявок;
- запрос дополнительной информации;
- предложение изменения уровня;
- фиксация причины решения.

### Administrator

Полный доступ к настройкам платформы.

Доступ:

- управление ролями;
- управление категориями;
- настройка правил;
- просмотр журнала действий;
- управление модераторами.

## Принципы модерации

1. Каждое решение должно иметь понятную причину.
2. Изменения TierList должны сохраняться в истории.
3. Важные действия модераторов должны попадать в журнал.
4. Жалобы должны иметь статусы `new`, `in_review`, `resolved`, `rejected`.
5. Пользователь должен понимать, почему его контент скрыт или изменён.
6. Удаление должно использоваться только там, где скрытия недостаточно.

## Минимальная очередь модерации

Для первой версии достаточно трёх разделов:

1. Жалобы на форум.
2. Проверка TierList.
3. Журнал действий модераторов.
