# CPVP.PRO information architecture

## Основная идея

CPVP.PRO должен быть единой точкой входа для Crystal PvP-сообщества: обучение, рейтинги игроков, профили и форум находятся в одном продукте и используют общую навигацию.

## Карта публичных разделов

```text
/
├── learn
│   ├── guides
│   ├── mechanics
│   └── mistakes
├── tiers
│   ├── overall
│   ├── categories
│   └── history
├── players
│   └── :playerSlug
├── forum
│   ├── categories
│   ├── topics
│   └── :topicSlug
├── rules
└── about
```

## Карта разделов аккаунта

```text
/account
├── profile
├── progress
├── notifications
└── settings
```

## Карта разделов модерации

```text
/moderation
├── reports
├── tier-review
├── forum-review
└── audit-log
```

## Основная навигация

Публичная навигация первого уровня:

1. Главная.
2. Обучение.
3. TierList.
4. Игроки.
5. Форум.
6. Правила.

В профиле пользователя отдельно доступны настройки, уведомления и прогресс обучения. Инструменты модерации отображаются только пользователям с соответствующей ролью.

## Приоритет первого релиза

Для первой полноценной версии достаточно реализовать:

1. Главную страницу.
2. Список материалов обучения.
3. TierList.
4. Публичные профили игроков.
5. Форум с категориями и темами.
6. Базовые аккаунты.
7. Модерацию жалоб и рейтингов.
