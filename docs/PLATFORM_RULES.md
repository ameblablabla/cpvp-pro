# CPVP.PRO platform rules

## Назначение

Эти правила задают базовые нормы поведения на CPVP.PRO. Перед публичным запуском текст нужно перечитать и утвердить отдельно.

## Общие правила

1. Уважайте других участников платформы.
2. Не публикуйте заведомо ложную информацию о себе или других игроках.
3. Не выдавайте себя за другого пользователя, модератора или администратора.
4. Не используйте платформу для спама и навязчивой рекламы.
5. Не публикуйте материалы, нарушающие применимые правила и законы.
6. Не пытайтесь мешать работе сайта или обходить ограничения платформы.

## Профили игроков

- Имя профиля должно быть читаемым и уместным.
- Аватар и описание не должны содержать оскорбительный контент.
- Подтверждённый статус выдаётся только после проверки.
- История TierList должна отображаться прозрачно.

## TierList

- Решения по TierList принимаются по отдельным правилам.
- Спорные решения можно отправить на повторную проверку.
- Давление на reviewers и модераторов не допускается.
- Фальшивые материалы для проверки могут привести к ограничению доступа.

## Ограничения

При нарушении правил могут применяться:

1. Предупреждение.
2. Скрытие материала.
3. Ограничение отдельных функций.
4. Временная блокировка.
5. Постоянная блокировка при серьёзных или повторных нарушениях.

## Апелляции

Пользователь может запросить пересмотр решения, если считает его ошибочным. Для этого нужно указать решение, причину несогласия и дополнительные материалы.
