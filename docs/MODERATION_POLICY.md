# CPVP.PRO moderation policy

## Назначение

Этот документ описывает базовый порядок модерации CPVP.PRO. Перед публичным запуском его нужно перечитать и утвердить отдельно.

## Основные принципы

1. Решения должны быть понятными и проверяемыми.
2. Пользователь должен видеть причину ограничения.
3. Похожие нарушения должны обрабатываться одинаково.
4. Важные действия модераторов должны фиксироваться.
5. Апелляции должны рассматриваться отдельно от исходного решения.

## Типы обращений

```text
forum_report
tier_review
profile_report
appeal
```

## Статусы

```text
new
in_review
resolved
rejected
```

## Базовый процесс

1. Обращение попадает в очередь.
2. Модератор проверяет материалы.
3. При необходимости запрашивается дополнительная информация.
4. Принимается решение.
5. Решение фиксируется с краткой причиной.
6. Пользователь получает уведомление.

## Возможные действия

- предупреждение;
- скрытие контента;
- редактирование заголовка;
- закрытие темы;
- временное ограничение функций;
- временная блокировка;
- постоянная блокировка при серьёзных или повторных нарушениях.

## Апелляции

Для апелляции пользователь указывает:

- исходное решение;
- причину несогласия;
- дополнительные материалы;
- желаемый результат.

## TierList review

Изменения рейтинга должны хранить:

- категорию;
- предыдущий уровень;
- новый уровень;
- дату;
- краткую причину;
- статус проверки.
