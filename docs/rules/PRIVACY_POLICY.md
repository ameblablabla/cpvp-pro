# CPVP.PRO privacy policy

> Legal draft placeholder. Review before public launch.

## Data categories

CPVP.PRO may store only data required for platform features, such as:

- Discord account identifier;
- Minecraft UUID;
- current and previous Minecraft usernames;
- profile fields;
- learning progress;
- subscription status;
- TierList history;
- moderation and appeal records;
- notification settings.

## Sensitive data

CPVP.PRO must never request or store:

- Microsoft password;
- Minecraft password;
- Discord password;
- session token;
- launcher token;
- backup code;
- email password.

## Account linking

Minecraft linking should use an official Microsoft OAuth flow. Users must be told what is verified, what data is received and why the link is required.
